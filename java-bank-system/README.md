## Xây dựng một hệ thống quản lý ngân hàng hỗ trợ các chức năng chính sau:

- Quản lý tài khoản khách hàng (CRUD)
- Chuyển tiền giữa tài khoản (sử dụng synchronized để tránh xung đột dữ liệu)
- Xử lý đa luồng để xử lý giao dịch (sử dụng ExecutorService)
- Lưu trữ và truy xuất dữ liệu tài khoản (sử dụng File I/O và Serialization)
- Sử dụng Collections Framework (List, Map, Queue để quản lý tài khoản và giao dịch)
- Xử lý ngoại lệ (try-catch-finally, custom exceptions)
- Sử dụng Java 8+ (Stream API, Lambda Expressions, Functional Interfaces)
- Quản lý bộ nhớ và tối ưu hiệu suất (Garbage Collection, Heap & Stack Memory)
- Sử dụng Reflection API để tự động kiểm tra thông tin lớp và phương thức
